# HTML Practical Application Activity 2

Open `activity.html` in a browser.

Before submission, create the required `dom-tree.png` screenshot:
1. Open the page in Chrome.
2. Right-click → Inspect.
3. Use the Elements panel.
4. Expand the HTML tree until at least 5 nested elements are visible.
5. Make sure the IDs from the activity can be identified.
6. Save the screenshot as `dom-tree.png` in this folder.

Git branch:
`cafe-shayna-act-2`

Commands:
```bash
git add .
git commit -m "Add HTML activity: images, hyperlinks, multimedia, useful tags, DOM"
git push origin cafe-shayna-act-2
```

Then open a Pull Request from the activity branch into `main`.
